# Retail Sales Analysis Dashboard | Power BI

## Project Overview

This project analyzes retail sales data to identify sales trends, product performance, customer behavior, and business opportunities using Power BI.

## Tools Used

* Power BI
* SQL
* Microsoft Excel
* DAX
* Power Query

## Key Analysis

* Total sales and revenue analysis
* Product category performance
* Regional sales comparison
* Monthly and yearly sales trends
* Key Performance Indicators (KPIs)

## Data Preparation

* Cleaned and transformed data using Power Query.
* Validated data for missing and duplicate records.
* Prepared data for analysis and visualization.

## Dashboard Features

* Interactive charts and visualizations
* KPI cards
* Date and category filters
* Sales performance comparisons

## Project Files

* Power BI report (`.pbix`)

## Objective

To demonstrate practical skills in data cleaning, data analysis, data visualization, and business reporting using Power BI.
